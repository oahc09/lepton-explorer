# Lepton Explorer — Windows 11 文件资源管理器复刻 · 设计规格

- **日期**：2026-06-13
- **状态**：已实现（配套 plans/IMPLEMENTATION.md 与 acceptance/README.md）
- **平台**：Windows 10、Windows 11
- **框架**：Tauri v2（Rust 后端 + React/TypeScript 前端）
- **本规格覆盖**：Phase 0（基础纵切）+ Phase 1（核心可用版）
- **参考资料**：
  - [Keyboard shortcuts in Windows — Microsoft Support](https://support.microsoft.com/en-us/windows/keyboard-shortcuts-in-windows-dcc61a57-8ff0-cffe-9796-cb9706c75eec)（官方快捷键清单，已逐项核实）

## 1. 目标

构建一个桌面应用，**像素级复刻 Windows 11 文件资源管理器的外观、布局与操作习惯**，使其在 Windows 10 与 Windows 11 上均可运行，日常使用体验与系统资源管理器一致：浏览目录、八种视图、完整的文件操作、撤销/重做、回收站删除、排序与列、缩略图与文件类型图标、文件监听自动刷新、全套键盘快捷键、Win11 现代上下文菜单、快速访问 / 此电脑导航、主页（快速访问 / 收藏 / 最近）、当前文件夹搜索、属性对话框、深色/浅色主题 + Mica 背景。

## 2. 范围

### 2.1 本规格包含（Phase 0 + Phase 1）

- Tauri v2 工程脚手架与窗口（自定义 Mica 标题栏、窗口按钮、深/浅主题）。
- 完整 UI 骨架：工具栏（后退/前进/向上/刷新）、面包屑地址栏（含路径编辑模式）、搜索框、命令栏（新建/剪切/复制/重命名/共享/删除/排序/视图/更多）、导航窗格、主视图、状态栏。
- 八种视图模式：超大图标、大图标、中图标、小图标、列表、详细信息、平铺、内容。
- 文件操作：新建文件夹、新建文件、重命名、复制、剪切、粘贴、删除入回收站、永久删除、打开（系统默认程序）。
- 撤销 / 重做。
- 选择：单击、Ctrl+点击、Shift+点击、Ctrl+A、Ctrl+方向+空格、橡皮筋框选（图标视图）。
- 排序与列（名称、修改日期、类型、大小；列宽可拖、列头可点排序）。
- 图片/视频缩略图（系统级）与文件类型/特殊图标（系统级）。
- 文件监听：外部变更自动刷新当前视图（去抖）。
- 全套快捷键（见 §9）。
- Win11 现代上下文菜单（文件 / 文件夹 / 空白处，自研）。
- 导航：面包屑段点击、同级下拉、地址栏编辑、后退/前进/向上历史、F5 刷新。
- 导航窗格：主页、Gallery（占位）、OneDrive（如存在则列为节点，不实现同步）、此电脑（桌面/文档/下载/音乐/图片/视频 + 盘符 + 网络）、固定/常用文件夹。
- 主页：快速访问（固定 + 常用文件夹）、收藏（文件）、最近（文件）。
- 当前文件夹搜索（含子目录，流式结果）。
- 属性对话框（常规信息：类型、位置、大小、占用、修改/创建/访问时间、属性；多选时为汇总）。

### 2.2 本规格不含（显式延后至后续阶段）

| 阶段 | 内容 |
|---|---|
| Phase 2 | 标签页（新建/关闭/拖拽重排/撕出新窗口/Ctrl+数字切换）、多窗口、预览窗格、详情窗格、拖放（标签页间/标签页内/系统外文件） |

## 3. 架构

```
┌──────────────────────────────────────────────────────┐
│ 前端  WebView2 · React + TypeScript                    │
│   UI：标题栏 / 工具栏 / 面包屑 / 搜索 / 命令栏 /        │
│       导航窗格 / 主视图(8 视图) / 状态栏 / 属性 / 搜索  │
│   状态：Zustand（位置+历史 / 选择 / 视图 / 剪贴板 /     │
│               撤销栈）                                  │
│   适配：hooks → invoke() + 事件订阅                     │
└──────────────┬───────────────────────────────────────┘
               │  Tauri IPC（invoke 命令 + 事件）
┌──────────────▼───────────────────────────────────────┐
│ 后端  Rust（tokio）                                     │
│   模块：fs_ops / watch / thumbnails / shell_icons /     │
│         special / search / undo_support / jobs          │
│   依赖：notify, trash, windows, jwalk, serde, anyhow    │
└──────────────┬───────────────────────────────────────┘
               │  Windows API（shell / fs）
               ▼
```

设计原则：每个 Rust 模块与 React feature 各司一职、通过明确接口通信、可独立测试；前端不直接接触文件系统，一切经后端命令。

## 4. UI 规格（严格对照 Win11）

自上而下、从左到右：

1. **标题栏（自定义、Mica）**：单标签占位（当前文件夹名 + 图标）｜右侧窗口按钮（最小化、最大化/还原、关闭）。关闭按钮 hover 背景为红 `#C42B1C`、前景白；其余按钮 hover 为半透明白/黑（依主题）。Mica 使标题栏透出桌面壁纸的柔和色调。
2. **工具栏行**（约 48px 高）：
   - 后退 `←`、前进 `→`、向上 `↑`、刷新 `↻`，各约 36×36，禁用态置灰。
   - **面包屑地址栏**：药丸形（约 32px 高）。显示当前路径分段，段间用 `›` 折页分隔；最左为当前文件夹图标。点击段 → 导航到该段；点击段间折页 → 弹出该层同级目录下拉；末段为纯文本高亮。`Alt+D` / `Ctrl+L` / `F4` 或双击 → **路径编辑模式**（原始路径输入框，回车导航、Esc 取消）。
   - **搜索框**：右侧药丸（约 240px），放大镜图标 + 占位"搜索 {当前文件夹名}"。`Ctrl+E` / `Ctrl+F` 聚焦。
3. **命令栏**：左对齐。`新建▾`（下拉：新建文件夹 + 新建文件类型）｜`剪切` `复制` `重命名` `共享` `删除`（图标，随当前选中项启用/禁用）｜`排序▾`（名称/修改日期/类型/大小 + 升序/降序切换）｜`视图▾`（8 视图列表，当前打勾；底部 `显示` 子菜单：导航窗格✓ / 展开到当前文件夹 / 文件扩展名 / 隐藏项）｜`… 更多`（选项 / 属性 等）。
4. **导航窗格**（左，默认 ~240px，可拖拽调宽，可隐藏）：树形。节点：`主页`、`Gallery`（占位节点，Phase 1 不实现内容聚合）、`OneDrive`（存在则显示为节点，仅作本地文件夹入口，不同步）、`此电脑`（展开：桌面、文档、下载、音乐、图片、视频，再列各盘 C:/D:…）、`网络`（占位节点，Phase 1 不枚举网络资源）、固定与常用文件夹。每项 = 折页 + 图标 + 名称；选中 = 主题强调色高亮；hover = 浅高亮。占位节点点击给"将在后续阶段提供"提示。
5. **主视图**（中央，占主区）：当前视图模式渲染。**详细信息**视图含列头行（名称/修改日期/类型/大小），列宽可拖拽、列头可点击排序（含升降序箭头）。双击文件夹 → 进入；双击文件 → 系统默认程序打开。图标视图支持橡皮筋框选。
6. **状态栏**（底部）：左 "X 项"（有选中时显示"已选 X 项"）｜右 视图尺寸滑块（在超大 ↔ 详细信息之间）。
7. **属性对话框**（`Alt+Enter` 或右键 → 属性）：Win11 风格弹窗，常规信息标签页（类型、位置、大小/占用、修改日期、创建日期、访问日期、属性只读/隐藏勾选）；多选时显示汇总。

配色与字体：Segoe UI Variable（回退 Segoe UI）；深色与浅色两套色板，随系统主题切换；圆角、间距对照真机截图精确还原（设计实现阶段产出尺寸清单）。

## 5. 后端模块（Rust）

| 模块 | 职责 | 关键依赖 |
|---|---|---|
| `fs_ops` | 列目录（并行）、读元数据、建文件夹/文件、重命名、复制、移动、删除入回收站、永久删除、打开项、批量带进度与冲突 | `jwalk`、`trash`、`windows` |
| `watch` | 监听当前目录树变更，去抖后发 `fs-changed` | `notify` |
| `thumbnails` | 系统级缩略图（图片/视频/文档），按 path+mtime+size 缓存到磁盘 | `windows`（`IShellItemImageFactory`） |
| `shell_icons` | 文件类型图标与特殊图标（文件夹/驱动器/特殊文件夹），缓存 | `windows`（`SHGetFileInfo`） |
| `special` | 枚举特殊文件夹、驱动器、回收站路径 | `windows`、`dirs` |
| `search` | 当前文件夹+子目录递归通配搜索，流式返回结果 | `ignore` 或自实现 |
| `undo_support` | 为前端提供可逆操作所需的后端能力（如回收站还原路径） | `trash` |
| `jobs` | 长任务进度事件、取消（job_id → cancel）、部分回滚 | `tokio` |

所有命令返回结构化结果或结构化错误（见 §8）。

## 6. 前端结构（React + TS）

- `features/explorer/`：`TitleBar`、`Toolbar`、`Breadcrumb`、`SearchBox`、`CommandBar`、`NavPane`、`FileList`（含 8 个 view renderer + 虚拟化）、`StatusBar`、`PropertiesDialog`、`ContextMenu`、`dialogs/`（进度、冲突）。
- `state/`（Zustand）：
  - `locationStore`：当前路径、后退/前进/向上历史栈。
  - `selectionStore`：当前选中集合、锚点、最近焦点。
  - `viewStore`：视图模式、排序列+方向、列宽、显示开关（扩展名/隐藏项）。
  - `clipboardStore`：复制/剪切源 + 模式。
  - `historyStore`：撤销/重做栈（每项含操作类型 + 可逆数据）。
- `hooks/`：`useExplorer`（封装 invoke + 事件订阅，统一喂给 UI）、`useShortcut`、`useDirectoryWatch`。
- **虚拟化**：`@tanstack/react-virtual`，应对上万文件目录，保证滚动流畅。
- **样式**：手写 CSS 复刻 WinUI 3；不使用通用组件库以求像素还原；CSS 变量承载两套主题色板。

## 7. 数据模型与 IPC 契约

### 7.1 数据模型

```ts
interface Entry {
  name: string;
  path: string;          // 绝对路径
  isDir: boolean;
  size: number;          // 字节（目录为 0 或汇总）
  modified: number;      // epoch ms
  created: number;
  accessed: number;
  typeLabel: string;     // "文件夹" / "JPEG 图像" 等
  ext: string;
  isHidden: boolean;
  isSystem: boolean;
  isReadOnly: boolean;
}
```

### 7.2 invoke 命令（前端 → 后端）

`list_directory(path, opts)`、`entry_metadata(path)`、`create_dir(path)`、`create_file(path)`、`rename(from, to)`、`copy_items(sources, dest, jobId)`、`move_items(sources, dest, jobId)`、`delete_to_trash(paths, jobId)`、`delete_permanent(paths, jobId)`、`restore_from_trash(info)`、`open_item(path)`、`get_thumbnail(path, size)`、`get_icon(key, size)`、`special_folders()`、`list_drives()`、`search(root, query, jobId)`、`get_properties(path)`、`cancel_job(jobId)`。

### 7.3 事件（后端 → 前端）

`fs-changed { path }`、`job-progress { jobId, done, total, currentName, phase }`、`search-result { jobId, entries }`。

## 8. 错误处理

后端命令失败返回结构化错误 `{ kind, message, path? }`，`kind` 取值：`NotFound`、`PermissionDenied`、`AlreadyExists`、`InvalidName`、`DiskFull`、`InUse`、`Cancelled`、`PartialFailure { failed: [...] }`、`Unknown`。

前端按 kind 呈现：
- 单项冲突（复制/移动/重命名遇同名）：弹 Win11 风格冲突对话框，提供"替换 / 跳过 / 保留两者（自动重命名）"，支持"对所有项应用"。
- 权限/占用等：对话框说明原因，可"重试 / 跳过 / 取消"。
- 列目录无权限：主视图显示空态 + 提示。
- 长任务可取消；复制/移动取消时保留已成功项，回滚记录入撤销栈（可选）。

受保护与系统项视为只读；删除失败给明确原因。

## 9. 行为规格

### 9.1 选择
单击选中并设为焦点；双击打开。`Ctrl+点击`增减单个；`Shift+点击`范围选（详细信息按行、图标视图按显示顺序）；`Ctrl+A` 全选；`Ctrl+方向+空格`增减焦点项；图标视图支持橡皮筋框选。方向键移动焦点；`空格`切换焦点项选中。

### 9.2 文件操作
- 复制/剪切写入内部 `clipboardStore`（剪切标记源）。粘贴时执行复制或移动。
- 复制/移动为长任务，发进度事件，显示 Win11 风格进度对话框（当前文件名、进度条、取消）。遇冲突按 §8 处理。
- 跨卷移动 = 复制后删源；同卷移动优先原子重命名。
- 删除：`Delete` / `Ctrl+D` → 回收站；`Shift+Delete` → 永久删除（二次确认）。
- 打开：`open_item` 调用系统默认程序（文件）或导航（文件夹）。

### 9.3 撤销 / 重做
`historyStore` 记录每个用户操作的可逆项：
- 删除入回收站 ↔ 从回收站还原。
- 重命名 ↔ 改回原名。
- 复制 ↔ 删除复制产物。
- 移动 ↔ 移回原位。
- 新建文件夹/文件 ↔ 删除新建项。
`Ctrl+Z` 弹出栈顶逆运算并执行；`Ctrl+Y` 重做。逆运算所需后端能力（如还原路径）由 `undo_support` 提供。

### 9.5 导航与刷新
面包屑段点击 / 同级下拉 / 地址栏编辑均触发导航；导航更新 `locationStore` 并压入历史；`F5` 重新读取当前目录；`Ctrl+R` 同。

### 9.6 文件监听
进入目录时 `watch` 订阅该目录（递归一层即可覆盖典型场景，深层按需）。变更去抖（约 300ms）后发 `fs-changed`，前端刷新当前视图（保留选择与滚动位置尽量稳定）。离开目录时取消订阅。

### 9.7 搜索
聚焦搜索框输入查询 → `search(root, query)` 递归匹配文件名（大小写不敏感、支持 `*`/`?` 通配）→ 流式 `search-result` 事件 → 主视图切换为结果列表；清除查询恢复原目录。

- **组件测试**（React Testing Library）：上下文菜单项随目标类型变化、属性对话框字段、冲突对话框选项。
- **界面验收比对**：界面还原度的正式验收门槛，见 **§11**（与真机 Win11 截图零可见偏差比对，含基准采集、阈值与验收矩阵）。§10 的功能性测试与 §11 的视觉验收共同构成完成定义。
- **构建验证**：`cargo test`、`pnpm test`、`pnpm tauri build` 产出可在 Win10 与 Win11 运行的安装包/可执行文件，并在两个系统各冒烟一遍核心流程。

## 11. 界面验收：与 Windows 11 截图零偏差比对

> **本节为界面的硬验收门槛。** 实现完成的界面必须在受控条件下与真实 Windows 11 文件资源管理器（版本 23H2/24H2）的截图逐区域比对，达到"**零可见偏差**"方可视为该区域通过。任何区域未通过比对即视为缺陷，需修复后重比，直至全绿。

### 11.1 判据：零可见偏差（"不偏差"的可执行定义）

"一模一样"在工程上定义为：在 100% 缩放、相同分辨率/DPI、相同主题、相同数据集下，Lepton Explorer 与真机 Win11 截图**并排放置、同尺寸**时，评审者**观察不到可见差异**。各维度阈值：

| 维度 | 要求（最大允许偏差） | 说明 |
|---|---|---|
| 布局几何 | **≤ 1px**（100% DPI） | 控件位置、宽高、间距、内边距、圆角半径、对齐基线 |
| 核心颜色 | **色差 ΔE ≤ 2**（感知不可见） | 背景、面板、选中高亮、强调色、边框、文字、分隔线 |
| 字体 | **完全一致** | Segoe UI Variable（回退 Segoe UI），字号、字重、行高、字间距一致 |
| 图标 | **与系统图标一致** | 经 `IShellItemImageFactory` / `SHGetFileInfo` 取系统级图标；不得自绘替代 |
| 交互状态 | **逐状态比对** | 默认 / hover / 选中 / 多选 / 禁用 / 键盘聚焦 / 拖拽悬停 均须达标 |
| 抗锯齿 / Mica | **豁免逐像素**（见下） | 见 11.3 |

### 11.2 基准采集（Reference）

1. 在一台标准 Windows 11（23H2 或 24H2）真机上，**100% 缩放、1080p+ 分辨率、关闭辅助高对比度**，分别采集**浅色**与**深色**主题截图。
2. 使用固定数据集（一组约定好的文件夹/文件样本，放入 `docs/acceptance/dataset/` 描述），保证两边的目录内容一致可比对。
3. 截图按"区域 × 状态 × 主题 × 视图"命名，存入 `docs/acceptance/reference/`（该目录与命名规约随规格提交）。
4. 真机 Win11 截图即"黄金基准"，实现不得修改基准来迁就自身。

### 11.3 豁免项（仅这些允许微观差异，仍须视觉协调）

- **Mica / 亚克力背景**：因透出桌面壁纸，无法逐像素一致；但**色调与明度须匹配**（同壁纸下整体观感一致）。
- **字体抗锯齿 / ClearType 子像素渲染**：WebView2 与系统渲染存在微观差异，允许亚像素级差异，字形轮廓须一致。
- **窗口阴影 / 系统级窗口动画**：不在比对范围。

> 除以上三项外，**任何可见差异均判定为不通过**。

### 11.4 比对方法

1. **并排人工比对**：同一区域、同主题、同数据集、同尺寸截图左右并排，评审者目视找差异（主方法）。
2. **差分叠加**（辅助）：用像素差分工具（如 `pixelmatch`）对非 Mica 区域计算差异像素占比，要求 **< 0.5%**；Mica/标题栏区域跳过自动差分，仅人工比对。
3. **状态回放**：交互态（hover/选中/禁用等）须手动触发后截图比对，不可只比默认态。

### 11.6 流程与门禁

1. **实现前**：先按 11.2 采集对应区域的真机 Win11 基准截图入库。
2. **实现中**：每完成一个 UI 区域，立即按 11.4 与基准比对；不达标即在该区域迭代修复。
3. **阶段验收**：Phase 0 与 Phase 1 各设一个验收节点，必须**矩阵全绿**（11.5 每格 ✓ 通过）方可进入下一阶段 / 视为阶段完成。
4. **回归**：后续阶段改动 UI 时，重跑受影响区域的比对，防止还原度退化。
5. 基准截图与比对记录（通过/差异说明）随仓库一同提交，作为验收证据。

## 12. 风险与对策

| 风险 | 对策 |
|---|---|
| Mica / 自定义标题栏在 Win10 行为不同 | Tauri v2 窗口特效降级：Win10 回退到纯色标题栏，Win11 启用 Mica |
| 系统缩略图/图标 API 行为不稳 | 加超时与缓存；失败回退到通用类型图标 |
| 大目录（数万项）卡顿 | 主视图强制虚拟化；列目录并行；缩略图懒加载 + LRU 磁盘缓存 |
| 撤销逆运算跨会话失效 | 撤销栈仅限当前会话；关闭窗口即丢弃（与系统一致） |
| Win10/Win11 API 差异 | 后端按版本能力分支；差异集中在 `special`/`thumbnails` 模块 |
