## 4. 已知限制

- **删除不可撤销到原路径**：回收站还原在 `trash` crate 不可靠，Ctrl+Z 仅能撤销本次"删除"动作本身（文件已入回收站，可手动从回收站找回）。
- **"替换"模式粘贴的撤销**不会自动还原被覆盖的原文件（原文件已入回收站，可手动还原；"保留两者"/"跳过"模式可完整撤销）。
- 复制、跨卷移动、ZIP 压缩/解压、重做均带可取消进度弹窗（同卷移动为即时重命名）。取消操作在条目之间及条目内部均生效。
- "显示更多选项"为占位（未接入真实 Shell 经典菜单）。

### 6.2 自采中发现并修复的真实缺陷

第二次自采（details 视图）暴露一个缺陷：Name 列默认宽 600px，在 800×600 窗口下
修改日期/类型/大小 三列被挤出屏幕。Win11 会收缩 Name 列。

**修复**：Name 列改为 `minmax(80px, <width>)`（可缩到 80px），默认宽 300px
（`viewStore.colWidths.name`），主视图约 560px 宽度下四列全部可见。

> 自采工具（html2canvas）不支持 CSS-grid `minmax` 轨道，无法代表 details 列头/列宽；
> 真机 `tauri dev` + 系统截图可正常捕获。故自采可靠于非 grid 区域，grid 区域仍需用户真机比对。

### 6.3 真机比对流程（需用户执行，工具限制无法自动化）

1. 标准 Win11（23H2/24H2）真机，100% 缩放、1080p+、关闭高对比度，浅/深主题各一套。
2. 用固定数据集（见 `dataset/Dataset/`）在真机资源管理器与 Lepton Explorer 各打开一次。
3. 逐区域并排截图（区域矩阵见下），命名 `<app>-<区域>-<状态>-<主题>.png`。
4. 并排人工比对（主）+ 像素差分（辅助，非 Mica 区域差异占比 <0.5%）。
5. 任何"偏差"非空项回报，按 `../design.md` §11 目标修复后重比，直至全绿。

**采集区域矩阵（区域 × 状态 × 主题）**：标题栏（默认/关闭 hover 红）、工具栏（全启用/前进禁用）、
面包屑（浏览/编辑）、导航窗格（展开此电脑）、详细信息（默认/选中/多选/分组）、大图标、列表、平铺、内容、
命令栏（下拉展开）、右键菜单、属性对话框、预览/详情窗格、搜索下拉、主页、多标签、冲突弹窗、进度弹窗、
状态栏、拖放高亮。至少覆盖标题栏/工具栏/面包屑/导航窗格/详细信息/大图标/状态栏（核心）。

## 7. 布局与 DPI 稳定性

**窗口缩放**：`.app` flex 纵向 100vh；`.body` flex 行 `min-height:0` 让文件列表滚动而非挤出状态栏；
导航窗格固定 240px、主视图 `flex:1`；details 的 Name 列 `minmax(80px, <width>)` 窄窗下收缩保其他列可见；
图标平铺换行。600×400 自采确认无溢出/裁剪/横向滚动条。

**附加保障**：`tauri.conf.json` 设 `minWidth:520 / minHeight:320`（与 Win11 一致的最小尺寸）；
工具栏 `overflow:hidden`、面包屑/命令栏 `min-width:0` + `flex-shrink:1` 保证任意尺寸无横向溢出。

**DPI 缩放（125%/150%/200%）**：WebView2(Chromium) 完全 DPI 感知，所有 px/字体/命中区随系统等比缩放；
Mica 为 OS 级、DPI 正确；自定义窗口按钮为 CSS px，随 UI 一同缩放。无需逐 DPI 资源（§11.1 零偏差目标定义在 100% DPI）。

**已知小项**：导航窗格固定 240px 不可拖拽（功能缺口，非稳定性问题）；命令栏窄窗下不折叠为"…"溢出菜单（未来增强，非正确性缺陷）。
