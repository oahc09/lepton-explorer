# 黄金基准（真机 Windows 11 截图）

在标准 Windows 11（23H2/24H2）真机上，按规格 §11.2 受控条件采集。文件命名：
`<区域>-<状态>-<主题>.png`，例：`titlebar-default-light.png`、`details-default-dark.png`。

## Phase 0 必采区域（浅/深各一套）

| 区域 | 状态 |
|---|---|
| 标题栏（Mica、窗口按钮） | 默认、关闭按钮 hover（红） |
| 工具栏（后退/前进/向上/刷新） | 全部启用、前进禁用 |
| 面包屑地址栏 | 浏览态 |
| 导航窗格 | 展开"此电脑" |
| 详细信息视图 | 默认、选中 |
| 大图标视图 | 默认 |
| 状态栏 | 无选中 |

## 真机基准采集步骤（需用户操作）

1. 在真机 Win11 上打开系统文件资源管理器，定位到 `Dataset/` 文件夹。
2. 设置为 100% 缩放、浅色主题，逐区域截图，按上表命名存入本目录。
3. 切换深色主题，重复采集。
4. 同样对 Lepton Explorer（`pnpm tauri dev` 运行后）在相同数据集、主题、缩放下截图，
   存为 `winf-<区域>-<状态>-<主题>.png`，用于并排比对。

> 真机 Win11 截图即"黄金基准"，不得为迁就实现而修改。
